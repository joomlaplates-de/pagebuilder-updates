# JP PageBuilder – Versions-Info

- [`CHANGELOG.md`](CHANGELOG.md) – alle Änderungen je Version, neueste oben.
- [`jppagebuilder.xml`](jppagebuilder.xml) – wird vom JP PageBuilder (Joomla 5/6, Astroid) einmal am Tag gelesen, um im
  Backend auf eine neue Version hinzuweisen. Sie enthält nur Versionsnummer, Kurzbeschreibung und Link zum Kundenbereich.

Updates werden manuell installiert. Mehr Informationen: https://www.joomlaplates.de
