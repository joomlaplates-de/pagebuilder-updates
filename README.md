# JP PageBuilder – Versions-Info

Diese Datei wird vom JP PageBuilder (Joomla 5/6, Astroid) einmal am Tag gelesen, um im Backend auf eine neue
Version hinzuweisen: [`jppagebuilder.xml`](jppagebuilder.xml).

Sie enthält nur Versionsnummer, Kurzbeschreibung und Link zum Kundenbereich. Updates werden manuell installiert.
Mehr Informationen: https://www.joomlaplates.de
